# GameAITools.com

A practical, independent resource for discovering AI tools for game development.

## Project status

Initial website foundation is in development. The first release will be a fast, accessible static site with a curated tools directory, category pages, comparisons, and practical tutorials.

## Development

- Semantic HTML, responsive CSS, and lightweight JavaScript
- Python-based static site generation (planned)
- GitHub Pages deployment (planned)

## Editorial principles

- Verify tool capabilities and pricing against official sources before publishing.
- Clearly distinguish tested findings from vendor claims.
- Disclose affiliate and sponsored relationships.
- Prioritize useful, original guidance over thin or mass-produced pages.
